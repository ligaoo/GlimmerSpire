# 微光尖塔 · Glimmer Spire

一个完整的卡组构筑式 Roguelike 网页游戏（类《杀戮尖塔》）。三幕尖塔、随机地图、三大职业、
264 张卡牌、76 件遗物、12 种药水、53 个分支事件、9 个可解锁技能包、
**6 个联动主题（专属卡组 35 张/主题 + 专属敌人 + 36 个主题专属事件 + 30 名原著角色伙伴 + 独立闯关模式）**、
卡牌双升级分支、卡牌熔铸（两卡融合）、敌人词缀、三档难度与 20 级进阶、伙伴主动技能/双人羁绊/训练、
图鉴收集、每日挑战、无尽模式、自动存档——全部离线可玩，零依赖。

**🎮 在线试玩：<https://ligaoo.github.io/GlimmerSpire/>**

## 启动方式

```bash
node server.js          # 默认 http://127.0.0.1:8765
node server.js 3000     # 自定义端口
```

浏览器打开 `http://127.0.0.1:8765` 即可游玩。

> 也可以用任意静态服务器指向本目录（`python -m http.server` 等），游戏是纯前端应用。

## 玩法

- **目标**：攀登三幕共 45 层的尖塔，击败最终 BOSS「微光吞噬者」。登顶后可继续 **无尽模式** 挑战不断变强的敌人。
- **战斗**：回合制卡牌战斗。每回合 3 能量、抽 5 张牌；敌人头顶显示意图（攻击/防御/强化/削弱）。
- **地图**：每幕 15 层分支地图——战斗、精英、篝火、商店、事件、宝箱，路线自选。
- **构筑**：胜利后三选一拿牌。卡组越精简越强，善用商店移除、篝火锻造与净化事件。
- **快捷键**：`1-9` 出牌 · `E` 结束回合 · `Esc` 取消/关闭。
- **联动主题**：主菜单「🌀 联动主题」页签 → 选主题 → 进入镜域。见下方「联动主题」章节。

| 职业 | 风格 | 初始遗物 |
|------|------|----------|
| ⚔️ 剑士 | 力量叠加、重击、格挡流 | 燃烧之血（战斗胜利回血） |
| 🗡️ 游侠 | 中毒、飞刃「刃」、弃牌联动 | 蛇形之戒（首回合多抽 2 牌） |

## 🌀 联动主题（特殊卡组）

主菜单切到「**联动主题**」即可进入与经典模式完全分离的第二套玩法：**独立职业卡池、独立初始卡组与遗物、专属敌人与 BOSS，以及独立的闯关模式「镜域」**。

镜域与三幕尖塔的差别：

- 每片镜域 10~14 层，打赢该域 BOSS 直接进入下一域。把三片镜域全部打穿即通关。
- 地图上有两个专属节点：**🩸 咒物祭坛**（以生命/卡组为代价换力量）与 **🛡️ 镇魂结界**（净化污染、休整、升级）。
- 每走一层累积 **污染**：污染让你所有伤害提升，但敌人的生命与攻击也同步变强，并且进入战斗时镜域/领域之值更深——走多少路是你的取舍。
- 战斗中有一条 **镜域之值 / 领域之值** 量表：随回合上涨，**积满会反噬**（你掉血、敌人永久加力量）。部分卡牌可以主动降低它，形成「快攻 vs 稳住」的节奏博弈。

| 主题 | 初始遗物 | 核心机制 |
|------|----------|----------|

| 👐 咒术回战 | 咒力核心（开局 3 咒力 + 2 层领域） | **咒力**是战斗内燃料，可强化攻击牌（咒术·解按咒力加伤、茈按咒力爆发）；**咒术**牌每回合第一张免费；**黑闪**有 25% 几率暴击翻倍并回咒力（「六眼」可提升几率）；**领域展开**把咒力翻倍并转化为全场伤害 |

每个主题包含 **35 张专属卡**（含衍生牌，关键卡可双分支升级）、7 件专属遗物、9~12 种专属敌人与 3 个专属 BOSS、
**6 个主题专属事件**，还有 **5 名原著角色作为「伙伴」**（3 名开局可选 + 2 名商店限定，限 4 名随行）。
伙伴自带回合被动、出牌联动与**主动技能**，两名伙伴同队还能触发**双人羁绊**，商店可训练升级。
专属卡只会出现在主题局的奖励、商店与祭坛中，不会污染经典模式的三大职业卡池。

## 内容规模

- **卡牌 264 张**：三职业各 30 张上下（初始/普通/罕见/稀有）+ 7 张无色牌 + 3 种诅咒 + 状态牌与衍生牌，
  以及 **6 个联动主题的 216 张专属卡**（神秘复苏 40 张，其余每主题 35 张），全部可升级；关键卡支持 **双升级分支（A/B 二选一）**
- **卡牌熔铸**：篝火可把凑齐的两张材料卡融合为更强的全新卡牌（6 个配方：柴刀+棺材钉=诡异长枪、鬼爪+鬼火焚身=鬼焰狂澜、燃目+天眼通=洞玄真瞳、重刃+顺势斩=崩山巨锤、蛇击+致命毒素=蚀骨毒牙、灵火+生命虹吸=噬魂魔焰）；融合卡不进任何卡池，只能熔铸获得，熔铸优先消耗未升级的副本
- **主题专属事件 36 个**：每个联动主题 6 个世界观事件（午夜凶铃/王选演说/五庄观人参果/涩谷站台……），主题局 80% 概率出现
- **敌人词缀**：第二段起普通敌人概率携带 壁垒/坚韧/迅捷/荆棘/吸血/诅咒 六种词缀（战斗内有徽章提示，击杀额外赏金）
- **难度与进阶**：轻松/标准/困难三档起步；每主题/职业独立进阶 1-20 级（通关解锁下一级），敌人成长换积分加成
- **伙伴系统**：30 名原著角色（3 初始 + 2 商店限定 / 主题）——回合被动 + 出牌联动 + **主动技能（战斗中点击头像发动，每场一次）**
  + **双人羁绊**（如蕾姆+拉姆「姐妹同心」）+ **商店训练升级**（Lv.3 数值翻倍）
- **客串卡**：主题局 1.5% 概率奖励中出现其他主题的角色卡
- **图鉴收集**：卡牌/敌人/事件/伙伴/遗物五册图鉴，收集里程碑自动发放积分
- **每日挑战**：日期固定种子 + 每日轮换变异规则（廉价魔力/血月/玻璃大炮等 8 种），得分 ×1.5，含当日最佳前五成绩榜
- **种子挑战**：输入种子重放/分享同一局（结算页显示本局种子）
- **BOSS 二阶段**：所有 BOSS 血量过半时变身——力量提升并挣脱减益，配全屏横幅警示
- **战斗倍速**：战斗界面 1x/2x/3x 切换（偏好持久化）
- **卡组管理**：卡组/牌堆弹窗支持按费用/类型/稀有度/名称排序与类型筛选，双分支卡显示 A/B 角标
- **CI**：GitHub Actions 自动跑全部测试（fuzz 平衡护栏 + UI 冒烟 + 机制回归）
- **技能包系统（跨局成长）**：每局结算按得分累积积分，主菜单商店解锁 9 个职业技能包
  （每职业 3 个、共 27 张专属卡，开辟处决/毒爆/盾转/重生等全新流派），解锁后永久进入该职业卡池
- **联动主题**：6 套独立卡组 + 42 件专属遗物 + **30 名原著角色伙伴（3 初始可选 + 2 商店限定 / 主题，带卡牌联动）** + 59 种专属敌人（含 18 个专属 BOSS）+ 独立的「镜域」闯关模式
- **Build 联动体系**：格挡流（全身撞击+盾墙+路障）、消耗流（灵魂收割+献血仪式+破釜沉舟）、
  弃牌流（战术家+游走+钢铁风暴）、毒爆流（疫病蔓延+毒性引爆+催化+尸爆）、血偿流（献祭契约+灵魂撕裂+末日审判）、
  处决流（猎手标记+致命精准）、鬼物流（鬼王+彼岸花+阴阳眼）、咒力流（六眼+领域展开+黑闪+茈）、
  回归流（死亡回归+魔女的眷顾+暴食的权能）、光能流（红色警戒+泽佩里敖光线+等离子火花）、
  棍势流（千钧重棍+法天象地+大圣威仪）、羁绊流（羁绊勾拳+灭龙奥义·咆哮+这就是·妖精的尾巴）
- **敌人 90 种**：三幕各 6 种小怪、3 种精英、1 个 BOSS（阶段变化、召唤、狂暴机制）+ 59 种主题敌人
- **遗物 76 件**：开局增益、经济、战斗钩子、复活（凤凰羽）、主题专属（镇魂铃/贝塔胶囊/如意金箍棒/公会纹章）等
- **药水 12 种** · **事件 17 个**（多分支选择，有代价有回报）
- **战斗特效**：斩击轨迹、冲击环、护盾波纹、毒泡、BOSS 登场横幅、受击红晕、出牌残影、死亡溶解、黑闪全屏暴击
- **无尽模式**：通关后敌人按轮次缩放血量与伤害
- **自动存档**：战斗中实时保存（含主题局的污染、结界护佑等状态），刷新/关闭后可从主菜单继续
- **历史战绩**：总场次、登顶数、最佳分数、分职业胜场、各主题通关次数
- **立绘外挂位**：往 `assets/enemies/*.png`、`assets/heroes/*.png` 放图即可替换 emoji（见 assets/README.md）

## 技术

- 纯原生 HTML/CSS/JS，无任何框架与网络请求，双击 `index.html` 亦可直接游玩
- 引擎与 UI 完全分离（`js/engine.js` 不含 DOM），全状态可 JSON 序列化
- 数据驱动：`js/themes.js` 里「声明数据」即可新增联动主题（卡池/遗物/敌人/遭遇表/镜域节点），引擎与 UI 自动接管
- 种子随机（mulberry32），整局可由单一种子复现
- WebAudio 合成音效（可静音），Canvas 星空背景
- `test/fuzz.js`：Node 模糊测试——36 局随机全流程 + 30 局策略 Bot + 3 局强化 Bot（验证胜利与无尽路径）
  + **联动主题对局与机制单元测试**（鬼/魂火/阴阳眼/咒力/黑闪/领域/污染/封锁/精灵/死亡回归/光能/红色警戒/棍势/羁绊/伙伴购买与生效/存档回环），
  覆盖存档回环与平衡护栏。运行：`node test/fuzz.js`
- `test/uismoke.js`：极简 DOM 桩驱动真实 `ui.js`，把全部 6 个主题从第 1 层跑到通关，验证所有画面/弹窗/主题组件均可渲染。运行：`node test/uismoke.js`
- `test/v5.js`：v5 机制回归测试——主题事件/双升级分支/敌人词缀/难度进阶倍率/每日规则/双人羁绊/伙伴主动技能与训练/客串卡/图鉴里程碑。运行：`node test/v5.js`
