# 微光尖塔 · Glimmer Spire

一个完整的卡组构筑式 Roguelike 网页游戏（类《杀戮尖塔》）。三幕尖塔、随机地图、三大职业、
113 张卡牌、34 件遗物、12 种药水、17 个分支事件、9 个可解锁技能包、无尽模式、自动存档——全部离线可玩，零依赖。

**🎮 在线试玩：<https://ligaoo.github.io/GlimmerSpire/>**

## 启动方式

```bash
node server.js          # 默认 http://127.0.0.1:8765
node server.js 3000     # 自定义端口
```

浏览器打开 `http://127.0.0.1:8765` 即可游玩。

> 也可以用任意静态服务器指向本目录（`python -m http.server` 等），游戏是纯前端应用。

## 玩法

- **目标**：攀登三幕共 45 层的尖塔，击败最终 BOSS「微光吞噬者」。登顶后可继续 **无尽模式** 挑战不断变强的敌人。
- **战斗**：回合制卡牌战斗。每回合 3 能量、抽 5 张牌；敌人头顶显示意图（攻击/防御/强化/削弱）。
- **地图**：每幕 15 层分支地图——战斗、精英、篝火、商店、事件、宝箱，路线自选。
- **构筑**：胜利后三选一拿牌。卡组越精简越强，善用商店移除、篝火锻造与净化事件。
- **快捷键**：`1-9` 出牌 · `E` 结束回合 · `Esc` 取消/关闭。

## 三大职业

| 职业 | 风格 | 初始遗物 |
|------|------|----------|
| ⚔️ 剑士 | 力量叠加、重击、格挡流 | 燃烧之血（战斗胜利回血） |
| 🗡️ 游侠 | 中毒、飞刃「刃」、弃牌联动 | 蛇形之戒（首回合多抽 2 牌） |
| 🔮 术士 | 生命换力量、回响（首牌双发）、爆发 | 蚀刻颅骨（开局 5 格挡） |

## 内容规模

- **卡牌 113 张**：三职业各 30 张上下（初始/普通/罕见/稀有）+ 7 张无色牌 + 3 种诅咒 + 状态牌与衍生牌，全部可升级
- **技能包系统（跨局成长）**：每局结算按得分累积积分，主菜单商店解锁 9 个职业技能包
  （每职业 3 个、共 27 张专属卡，开辟处决/毒爆/盾转/重生等全新流派），解锁后永久进入该职业卡池
- **Build 联动体系**：格挡流（全身撞击+盾墙+路障）、消耗流（灵魂收割+献血仪式+破釜沉舟）、
  弃牌流（战术家+游走+钢铁风暴）、毒爆流（疫病蔓延+毒性引爆+催化+尸爆）、血偿流（献祭契约+灵魂撕裂+末日审判）、
  处决流（猎手标记+致命精准）
- **敌人 31 种**：三幕各 6 种小怪、3 种精英、1 个 BOSS（阶段变化、召唤、狂暴机制）
- **遗物 34 件**：开局增益、经济、战斗钩子、复活（凤凰羽）等
- **药水 12 种** · **事件 17 个**（多分支选择，有代价有回报）
- **战斗特效**：斩击轨迹、冲击环、护盾波纹、毒泡、BOSS 登场横幅、受击红晕、出牌残影、死亡溶解
- **无尽模式**：通关后敌人按轮次缩放血量与伤害
- **自动存档**：战斗中实时保存，刷新/关闭后可从主菜单继续
- **历史战绩**：总场次、登顶数、最佳分数、分职业胜场
- **立绘外挂位**：往 `assets/enemies/*.png`、`assets/heroes/*.png` 放图即可替换 emoji（见 assets/README.md）

## 技术

- 纯原生 HTML/CSS/JS，无任何框架与网络请求，双击 `index.html` 亦可直接游玩
- 引擎与 UI 完全分离（`js/engine.js` 不含 DOM），全状态可 JSON 序列化
- 种子随机（mulberry32），整局可由单一种子复现
- WebAudio 合成音效（可静音），Canvas 星空背景
- `test/fuzz.js`：Node 模糊测试——36 局随机全流程 + 30 局策略 Bot + 3 局强化 Bot（验证胜利与无尽路径），
  覆盖存档回环与机制单元测试。运行：`node test/fuzz.js`
