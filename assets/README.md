# 立绘资源说明

把 PNG 图片按下列文件名放进对应目录即可自动生效（无需改代码）；
没有图片的会自动回退为 emoji 显示，所以放任何子集都可以。

## 尺寸建议

- 怪物:`assets/enemies/<id>.png` — 建议 512×512 透明底 PNG,主体居中占 ~80%
- 英雄:`assets/heroes/<职业id>.png` — 建议 512×512 透明底,半身立绘
